# Changelog

## 7.0.0 — Native Windows rewrite
- Replaced the Python/Tkinter app with a C# / .NET 10 WPF desktop application.
- Added foreground application usage tracking with local JSON persistence.
- Added focus sessions with pause/resume and local history.
- Added configurable, reversible foreground app minimization.
- Added privacy controls to independently enable tracking and blocking, and clear local history.
- Removed Python source files and Python dependency manifests.

## 6.0.0
- Previous modular Python desktop implementation; retained in Git history only.
